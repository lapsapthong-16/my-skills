# My Skills

## Easy Install My Skills

Install every skill owned by this repo:

```bash
npx skills add lapsapthong-16/my-skills --skill parallel-goals --skill validator --skill repo-illustrations --skill repo-readme-writer --skill refactor-codebase --agent claude-code --agent codex --global
```

Restart Claude Code or Codex after installing.

## Easy Install External Tools

- [Caveman](https://github.com/JuliusBrussee/caveman): `curl -fsSL https://raw.githubusercontent.com/JuliusBrussee/caveman/main/install.sh | bash`
- [Caveman for Codex only](https://github.com/JuliusBrussee/caveman): `npx skills add JuliusBrussee/caveman -a codex`
- [Frontend Slides Claude plugin](https://github.com/zarazhangrui/frontend-slides): `/plugin marketplace add https://github.com/zarazhangrui/frontend-slides` then `/plugin install frontend-slides@frontend-slides`
- [Frontend Slides manual skill](https://github.com/zarazhangrui/frontend-slides): `git clone https://github.com/zarazhangrui/frontend-slides.git ~/.claude/skills/frontend-slides`
- [OpenSpec](https://github.com/Fission-AI/OpenSpec): `npm install -g @fission-ai/openspec@latest`
- [Ponytail for Codex](https://github.com/DietrichGebert/ponytail): `codex plugin marketplace add DietrichGebert/ponytail`
- [Ponytail for Claude Code](https://github.com/DietrichGebert/ponytail): `/plugin marketplace add DietrichGebert/ponytail` then `/plugin install ponytail@ponytail`
- [RTK with Homebrew](https://github.com/rtk-ai/rtk): `brew install rtk`
- [RTK with install script](https://github.com/rtk-ai/rtk): `curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh`
- [Matt Pocock skills](https://github.com/mattpocock/skills): `npx skills add mattpocock/skills --skill prototype --skill diagnosing-bugs --skill handoff --skill writing-great-skills --agent claude-code --agent codex --global`
